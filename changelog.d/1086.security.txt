Security: sk-* (FIDO/U2F) public keys are now structurally validated (P-256 curve and uncompressed point, or a 32-byte Ed25519 key; application must start with "ssh:"; no trailing fields), and an sk-* identity only accepts an sk-* signature of the same algorithm with the FIDO flags/counter trailer; a plain Ed25519/ECDSA signature or another sk-* algorithm is skipped rather than forwarded. The application string remains part of the key blob, so identical key bytes under different applications are distinct identities.
