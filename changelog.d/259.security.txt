Harden `diffie-hellman-group-exchange-*` against malicious server groups. The prime and generator are now bounded at the SSH2 string length before any bignum is allocated, and validated in order — structure, the negotiated minimum/need/maximum bit range, then bounded Miller-Rabin safe-prime checks for p and (p-1)/2 — before a DH key or modular exponentiation is ever produced. Malformed, out-of-range and cryptographically invalid groups, as well as degenerate server public values, are rejected before any shared secret is computed or released. A bit length inside the requested range alone no longer makes a group trustworthy [#259]
