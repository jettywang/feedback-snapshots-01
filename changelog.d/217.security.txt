The negotiated SFTP protocol version and the advertised extensions are now scoped to a single handshake. Reconnecting a reused Net::SFTP::Session resets them before the new FXP_VERSION arrives, so capabilities from the previous server can no longer be presented as the new server's. A second FXP_VERSION, a protocol version outside 1-6, and an extension advertised twice with conflicting values now raise Net::SFTP::NegotiationError without publishing partial state, and a duplicate FXP_VERSION no longer runs the open callbacks twice.
