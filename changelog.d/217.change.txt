Add `Session#confirmed_upload`/`confirmed_upload!` and `Operations::ConfirmedUpload`, a staged upload that records each confirmation separately: SSH authentication evidence, every WRITE acknowledged with its byte count, CLOSE, fsync@openssh.com when the server advertises it, size or read-back SHA-256 verification, and the final posix-rename@openssh.com. It never reports partial writes or an unknown final rename as complete success, reports directory-entry durability as unknown, and leaves the staging file retained when publishing fails. Also add `Session#fsync`/`fsync!`, `Session#posix_rename`/`posix_rename!` and `Session#extension?`. A successful `upload!` now documents that it only proves WRITE and CLOSE STATUS OK, not durable delivery.
